---
title: 从应用市场部署 Dify
description: 通过 Rainbond 应用市场安装 Dify，选择团队、等待组件运行并访问应用。
---

以 Dify 为例，直接从应用市场安装开源软件，完成后打开自己的 Dify 页面。

## 准备

- 已安装 Rainbond，并能登录控制台；还没有环境，先完成 [快速安装](./quick-install.mdx)。
- 服务器能联网下载镜像，资源满足所选 Dify 模板详情中的要求。

## 1. 找到 Dify

进入 **应用市场**，搜索 **Dify**，打开应用详情。确认版本、组件清单、资源要求和支持的 CPU 架构，再点击 **安装 / 部署**。

![在应用市场中选择 Dify](/img/video/app-store-install-step-2.png)

## 2. 选择团队并安装

选择要安装到的团队，按页面提示填写应用名称和必要配置，确认安装。Rainbond 会按模板创建组件和依赖关系。

进入应用拓扑，等待各组件进入运行中状态。Dify 包含多个组件，首次拉取镜像和启动需要一些时间。

![等待 Dify 组件运行](/img/video/app-store-install-step-4.png)

## 3. 打开 Dify

点击 Web 入口组件的 **访问**，按 Dify 页面引导初始化管理员账号，然后登录。

需要使用 AI 功能时，在 Dify 中配置可用的模型服务，再创建一个简单的聊天应用，发送一句话确认模型能够回复。

## 怎样算成功？

- Dify 的必要组件正常运行。
- 浏览器能打开 Dify，并完成管理员初始化和登录。
- 配置模型后，聊天应用能够正常回复。

组件长时间未运行时，点击异常组件查看事件和日志，先检查镜像下载、内存和配置。页面打不开时，检查 Web 入口的 HTTP 端口是否开启对外访问，以及当前电脑能否访问该地址。

后续要升级或备份，继续阅读 [Dify 私有化部署、升级和备份](/docs/how-to-guides/scenario-tutorials/dify-private-deployment)。
