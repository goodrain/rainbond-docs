以 **鲲鹏 ARM64 + 麒麟 V10** 为例，在一台可联网的服务器上安装 Rainbond，再部署一个应用验证结果。

## 准备

- 一台干净的 Linux 服务器，建议准备 4 核 CPU、8 GB 以上内存、50 GB 以上磁盘，部署应用时还需预留资源。
- 使用 root 账号操作，服务器能够访问公网软件源和镜像仓库。
- 7070、80、443 端口未被其他服务占用，并允许你的电脑访问这些端口。

先确认 CPU 架构：

```bash
uname -m
```

鲲鹏 ARM64 通常显示 `aarch64`。下方安装脚本会识别 `aarch64 / arm64` 和 `x86_64 / amd64`，选择对应架构的资源。其他指令集不能直接套用此教程。

## 1. 执行安装命令

在服务器终端执行：

```bash
curl -fL -o install.sh https://get.rainbond.com
bash ./install.sh
```

按脚本提示完成安装，等待输出 `Rainbond Installation Successful` 和控制台地址。此方式在一台服务器上启动 Rainbond 及内置 Kubernetes，适合先体验和验证环境。

## 2. 打开控制台

在自己的电脑浏览器中打开安装日志给出的地址，通常为：

```text
http://服务器IP:7070
```

按页面提示完成注册并登录，确认集群状态正常。如果日志给出的是内网地址，你的电脑也需要能访问该内网。

## 3. 部署一个应用

按照 [从 Git 仓库部署第一个应用](./git-project.md) 创建示例组件，等待构建和运行完成，再点击 **访问** 打开页面。

ARM64 环境下，应用的基础镜像和依赖也必须支持 ARM64；平台安装成功不代表任意 x86 应用都能直接运行。

## 怎样算成功？

- 安装脚本提示成功，控制台能打开并登录。
- 集群正常，示例组件构建成功并运行。
- 浏览器能打开示例应用页面。

安装报错时，先按脚本提示检查网络、内存、磁盘和端口；控制台打不开时，检查服务器防火墙或安全组是否允许访问 7070。其他问题见 [安装故障排查](/docs/troubleshooting/install)。
